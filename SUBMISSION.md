# Сдача работы

Решения сохранены в ветке `solution/vitastore-cost-reduction`. В `main` находятся исходные задания и правила репозитория. Pull request должен сравнивать эти две ветки.

Публикация пока не выполнена: локальный Git не получил учётные данные, а GitHub-коннектор вернул `403 Resource not accessible by integration` при попытке записи. Репозиторий на GitHub остался без опубликованных решений.

В контексте требуется публичный репозиторий с именем `cost-reduction`. Текущий `origin` указывает на публичный `mdchumakov/solution-architecture-3`; его имя не менялось. Перед сдачей нужно выбрать, использовать текущий репозиторий или создать `cost-reduction` и направить публикацию туда.

После настройки доступа для текущего `origin`:

```sh
git push origin main
git push -u origin solution/vitastore-cost-reduction
```

Затем открыть PR из `solution/vitastore-cost-reduction` в `main` и отправить ревьюеру ссылку на него.

## Заголовок PR

VitaStore: снижение затрат, подключение магазинов и облачная архитектура

## Описание PR

Подготовлены четыре задания: карта возможностей и Buy vs Build, BPMN подключения магазина, исправленная AS-IS и целевая архитектура, TCO для 100 магазинов на три года.

Касса использует локальный HAL и сохраняет наличные продажи при обрыве связи. SAP остаётся в HQ, Smart Fulfillment сохраняется как собственная система. Ошибки сопоставления SKU проходят проверку человеком до публикации каталога.

Учебная модель даёт 42,90% снижения TCO при указанных допущениях. Отдельно рассчитаны задержка внедрения, рост расходов и отсутствие денежного сокращения ФОТ.

Проверены BPMN по XSD OMG, связи между пулами, ссылки, схемы в браузере и итоговые расчёты. Пилот на реальном оборудовании не проводился. Начальная точка для ревью — корневой README, результаты проверок — REVIEW.md.
